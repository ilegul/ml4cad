# ML4CAD

Machine learning and data analysis project for coronary artery disease.

## Main areas

- Exploratory data analysis
- Data preprocessing and feature engineering
- Classification
- Survival analysis
- Random Survival Forest
- Model evaluation and interpretation
- Visualization and reporting

## Project structure

- data/raw: original input data, not tracked by Git
- data/interim: intermediate transformed data
- data/processed: final datasets used for modeling
- notebooks: exploratory and experimental notebooks
- src/classification: classification models
- src/survival: survival analysis and Random Survival Forest
- src/preprocessing: data cleaning and preprocessing
- src/features: feature engineering
- src/evaluation: metrics and model comparison
- src/visualization: plots and reporting utilities
- models: trained model artifacts, not tracked by Git
- reports: generated reports and figures
- tests: automated tests
- configs: configuration files
